# Changelog

## [0.2.0-local] - 2026-07-16 (ローカル翻案・upstream 未反映)

技術文書モードを追加。

### 追加

- `references/tech-writing.md`: 日本語技術文書(書籍の章、記事、解説文)の文章規範。整形、段落と論証の構成、論証の厳密さ、読み手の負荷管理、視点と語り、演出の抑制、LLMっぽい表現の禁止、冗長の排除、見出し、読者への誠実さ。
- SKILL.md に「技術文書モード」節: ブログ前提コアルール(伝聞・毒・中間温度・一人称・語尾崩し・「」制限・アカデミック自称禁止)の上書き表と reference への導線。
