# サムネイル画像レビュー（[thumbnail-generation.md](thumbnail-generation.md) の生成物対象）

Gemini等の画像生成AI + Claude の3ラウンド手法（[thumbnail-generation.md](thumbnail-generation.md)）で生成したサムネイル画像を、**自己レビューではなく**チェックリストで1項目ずつ突き合わせて検証する。1つでも該当したら該当ラウンドから再生成する。

---

## A. 整合性チェック（破綻検知・CRITICAL）

- [ ] ブランド要素（マスコット/ロゴ等）の数・構成が指定どおりか（欠落・重複はいずれも即再生成）
- [ ] ブランド要素を単体参照画像と視覚照合し、輪郭・パーツ配置・配色が一致しているか
- [ ] ブランド要素が単調に並んでいないか — 表情・ポーズにバリエーションがあり「見たくなる」構図になっているか
- [ ] 土台となった実写真の質感（建物・光の反射・素材感等）がイラスト化・描き替えされず維持されているか
- [ ] 🚨 **実在の看板・銘板・案内板等、実写真に写っている固有の文字情報が元の実写真と一致しているか**（誤生成されやすい・立体文字は後編集での補修が困難なため、誤りを検知したら Round 1 から新規セッションで再生成する）
- [ ] 固有名詞（地名・組織名等）のスペル/表記が正しいか（現地語表記・常用表記からの誤変換に注意）
- [ ] テキストが画面内に完全に収まっているか・最重要語が最も目立つ文字になっているか
- [ ] 括弧・引用符の開き・閉じが対応しているか
- [ ] 🚨 **架空要素の創作チェック**: 土台の実写真に無い図案（ロゴ・什器・壁面装飾等）が描き足されていないか
- [ ] 🚨 **ブランド要素の暴走チェック**: (a) ブランド要素が写実的な別人物・別物に変換されていないか (b) 見出し文字ブロックが増殖していないか・過度な煽り文句が追加されていないか (c) テキスト/イラストで土台画像の大部分が覆い隠されていないか (d) ブランド要素がコンテンツ内容（強い語・数値等）に引きずられて別のキャラクター/別物に置き換わっていないか

該当した場合、同一チャットでの1往復修正は軽微な場合のみ試み、それ以外は該当ラウンドの新規セッションからやり直す。

## B. CTR（クリック率）観点

以下は「ゴチャついた構図・伝わらない見出し・単調な表情」が指標を下げるという公開研究知見に基づく。1つでも未達なら、コンテンツフック追加ラウンドでの改善・またはRound2からの再生成で対応する。

- [ ] **視覚要素が3つ以内に収まっているか**（土台画像+ブランド要素+文字ブロック、程度。要素過多はCTRを下げる傾向がある）
- [ ] **画像単体を見ただけで「見ると何が分かるか」が伝わるか**（対象名・場所だけでなく、フック（独自性・数値等）が読み取れるか）
- [ ] **感情の強い表現になっているか**（驚き・興奮・喜び等。無表情/微笑みだけの単調な構図は弱い）
- [ ] **見出し文字が0〜3語程度で視認性が高いか**（長文詰め込みは認知摩擦を生みCTRを下げる）
- [ ] **縮小表示（一覧サムネイル相当のサイズ）でも上記が判読できるか**

## C. 機械チェック（補助・疑陽性あり得る）

文字の可読性・見切れを検出するスクリプトがあれば実行する（対象プロジェクトで用意する場合。無ければ目視のみで判断する）。機械チェックはあくまで補助であり、目視レビューの代替にはならない。

---

## 採点目安

- **PASS**: A（整合性）が全項目クリア、かつ B（CTR）が4項目以上クリア
- **REVISE**: A は全項目クリアだが B が3項目以下 → コンテンツフック追加ラウンドで改善を試みる
- **REGENERATE**: A に1項目でも該当 → 該当ラウンド（多くはRound 1）からの再生成が必要
