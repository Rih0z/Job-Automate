# workflows/research-intelligence/ — リサーチ・ニュース・SEO

業務ワークフロー「情報収集・分析」のハーネス。市場調査・ニュース収集・SEO分析に関するプロンプト集。レビューは共通で [review-research.md](review-research.md) を使う。

## news/ — ニュース収集

| ファイル | 用途 |
|---|---|
| [news/it.md](news/it.md) | ITニュースを収集・要約する |
| [news/craft-beer.md](news/craft-beer.md) | クラフトビール業界のニュースを収集・要約する |
| [news/trends.md](news/trends.md) | 指定分野のトレンドをリサーチする |
| [news/investment.md](news/investment.md) | 投資関連情報を収集・整理する |

## seo/ — SEO分析

| ファイル | 用途 |
|---|---|
| [seo/base.md](seo/base.md) | サイト・コンテンツのSEO基盤を設計する |
| [seo/trend-keywords.md](seo/trend-keywords.md) | 今トレンドのSEOキーワードを収集・分析する |
