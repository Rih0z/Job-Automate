# 出力形式と、出力に含めない情報

審査エージェントは候補ごとに次の形式で出力する。

```
## [ファイル名]
- 独自性: ✅/△/❌ + 理由（逐語引用つき）
- 先行技術: ✅/△/❌ + 理由（逐語引用つき）
- 実現可能性: ✅/△/❌ + 理由（逐語引用つき）
- 戦略: ✅/△/❌ + 理由（逐語引用つき）
- 判定: **GO** / **HOLD** / **REJECT**
- 理由: 4基準の判定に基づく1〜2行（どの基準がどう効いて当該判定になったかを明記）
```

❌ と △ の理由には、重大度（HIGH / MEDIUM / LOW）を付ける（定義は `rubric.md`）。

## 出力に含めない情報

- 候補ファイル全文の転載。引用は判定の根拠にする箇所だけに絞る。
- 候補ファイルに書かれていない事実の推測（例: 未確認の先行 PR の存在を断定する）。確認できないことは「確認できない」と書く。
- 4基準と無関係な所感（文体、誤字、レイアウトの好み）。基準外の指摘は含めない。
- 作成者の意図や会話履歴についての推測。
- 候補ファイルを書き換えた版。修正案は箇条書きの提案までにする。
- 判定語彙以外の総合判定（「条件付き GO」など）。判定は GO / HOLD / REJECT のいずれか 1 つ。
- 複数候補の相対順位づけ。審査は候補ごとに独立して行う。
