# レビュアー定義・共通原則・判定帯（repo 固有ファイルが無い環境用）

`.claude/agents/readonly-reviewer.md` と `.claude/skills/_shared/review-rubrics.yaml` が無い環境で、SKILL.md と references/ だけでレビューを完結させるための要点。両ファイルがある環境ではそちらを優先する。

## 審査エージェントの条件（readonly-reviewer の代替）

- Agent ツールに `general-purpose` を指定し、prompt 冒頭に「ファイルを作成・変更・削除しない」と明記する。
- Bash を使う場合は読み取りと検査に限る。結果はファイルに書かず応答本文で返す。
- 実装意図や会話履歴は渡さない。基準に無い好みの指摘は optional として分け、基準違反だけを blocking にする。

## 共通原則（common_principles の要点）

- 証拠主義: 推測で採点しない。対象 HTML の記載のみで評価し、記載が不十分な軸は採点レンジの下限で採点する。
- 引用義務: 各軸のスコアに、該当する HTML 内の記述（クラス名、見出し、スライド番号、CSS 宣言など）を 1 つ以上引用する。
- 非破壊: レビューだけを行い、対象ファイルを編集・実行しない。改善点は提案として書き、修正は作成者が行う。

## 総合点と判定（rank5_100 の要点）

| 判定 | 点数 | 意味 |
|---|---|---|
| S | 90-100 | そのまま使える。追加修正は不要 |
| A | 80-89 | 軽微な修正・補強で次工程へ進める |
| B | 70-79 | 修正推奨。特定の観点で深掘り・再検討が必要 |
| C | 60-69 | 大幅な修正・再検討が必要 |
| D | 0-59 | 根本的な見直し・書き直しが必要 |

## 重大指摘の扱い

軸別の採点目安で最下帯（0-9 点）に当たる軸は「重大指摘」として、改善提案の先頭に置く。総合点が高くても、その軸の指摘は省かない。
