# リサーチ成果物の評価観点（5項目・各20点・合計100点）

`research-deliverable-review` のレビューエージェントが Read して採点に使う。観点・配点・採点目安・評価調整の正本はこのファイル。

## 目次

1. 情報の正確性・信頼性
2. 網羅性・カバレッジ
3. 分析の深度・洞察
4. 構成・可読性
5. 実用性・アクション接続
6. 評価調整（プロンプト種別に応じる）


## 1. 情報の正確性・信頼性【配点20点】
目的: 収集された情報が正確であり、信頼できるソースに基づいているかを確認する。事実と推測の区別、データの鮮度、バイアスの有無を評価する。
- 引用されたソースが主要メディア・専門メディア・公的機関など信頼性の高い情報源であるか
- 各情報に引用元URLが明記されており、アクセス可能か
- 事実と推測・見解が明確に区別して記述されているか
- 掲載データの日付・時点が明記されており、情報の鮮度が確認できるか
- 数値データ（市場規模・成長率・検索ボリューム等）に出典が付されているか
- SNSのみを一次ソースとする情報が排除されているか
- 特定企業・製品・立場に偏ったバイアスが含まれていないか
- フェイクニュース・未確認情報が排除されているか
- 課金登録が必要なソースに偏っていないか
- **文字数制限付きの要約（70字以内の要約・50字以内の見出し等）で、具体的な数値・日付・固有名詞が「迅速に」「大幅に」等の曖昧な言葉に置き換わっていないか**（要約という圧縮処理自体が情報を失わせる現象。長文の中間位置の情報が軽視されるLost-in-the-Middleとは原因が別なので混同しない — 原文に確認可能な具体値がある限り、要約後もその値を残せているかを個別に確認する）
- 数値ごとに、系列（スポットか先物か ETF か、単月か移動平均か）、時点（寄り付き前、場中、終値、対象月）、出典の 3 点が書かれているか。限定語の付いた数値を、限定語を外して確定値のように書いていないか
- 検索エンジンの要約、AI 要約、ページ抽出ツールの出力だけを根拠にした数値や引用が無いか（原文の生テキストで確かめた値か）
- 「記載なし」「公表されていない」のような不在の主張に、探した資料の範囲が書かれているか
- 取得時刻で変わる値（相場、件数、データ提供元が後から改訂する過去の値）に取得時刻が書かれ、保存した生データから再計算できる形になっているか
- 依頼文に書かれていた前提（政策の方向、ID と名称の対応など）を、確かめずに事実として書き写していないか

採点目安: 18-20=すべて信頼性の高いソース+引用元完備+事実/推測区別明確+バイアス排除 / 14-17=おおむね信頼性高いが一部引用元欠落・区別やや曖昧 / 10-13=信頼性にばらつき・引用元欠落が目立つ・バイアスの可能性 / 0-9=信頼性低い・引用元ほぼ無し・事実と推測が混在

## 2. 網羅性・カバレッジ【配点20点】
目的: リサーチ対象に対して必要な情報が漏れなく収集されているか、複数の視点を包含しているかを確認する。
- プロンプトで指定された主要トピック・カテゴリがすべてカバーされているか
- 指定された地域（シアトル・全米・日本等）すべてについて情報が収集されているか
- 同一トピックに対して賛否・異なる立場からの視点が含まれているか
- 関連するトレンド・背景情報との接続が示されているか
- グローバル視点とローカル視点の両方が提供されているか
- 該当ニュースが存在しないカテゴリについて「該当なし」と明記されているか
- SEO分析の場合: 検索意図・競合・ユーザーペインポイントの3要素が揃っているか
- ニュース収集の場合: 事実・影響・今後の見通しの3要素が揃っているか
- 時事の題材を選ぶ成果物の場合: 前の回に集めた話題の一覧だけでなく、直近数日の一次データ（市場なら直近数営業日の終値）で、その後に起きた大きな動きを確かめているか

採点目安: 18-20=指定カテゴリ・地域を完全網羅+複数視点+トレンド接続あり / 14-17=主要カテゴリ・地域はカバーだが一部視点・接続不足 / 10-13=明確な抜け漏れあり / 0-9=大幅に不足（指定範囲の半分以上欠落）

## 3. 分析の深度・洞察【配点20点】
目的: 単なる情報の羅列に留まらず、「So What?」の洞察が含まれているかを確認する。因果関係の分析、将来予測、アクション可能な示唆の有無を評価する。
- 個別のニュース・データに対して「だから何？」の洞察が添えられているか
- 複数の情報を横断した因果関係の分析が含まれているか
- 将来予測・トレンド予想が示されており、その根拠が明記されているか
- 表面的な要約ではなく、市場影響・業界へのインパクトが分析されているか
- SEO分析の場合: 競合の弱点を突く具体的な戦略が提案されているか
- ニュース収集の場合: 各ニュースの相互関連性が示されているか
- データの傾向・パターンが抽出されているか
- 短期的影響と中長期的影響の両方が考察されているか
- **明確な数値差・構造的パターンが観測された箇所で、それを「測定誤差」「たぶん別の理由」のように十分な根拠なく片付けていないか**（大きな数値差・突出した指標等は、まず機械的な仕組みレベルでの説明を検討すべきで、外部要因への帰属は根拠を示した場合のみ許容する）
- 集計の結論文に、除外した条件と集計の窓（何日間か）が書かれているか。途中で付けた除外条件が書かれないまま「どれも〜を超えない」のような全体の結論になっていないか
- キーワードや話題の件数を需要の根拠にする場合、短い語の部分一致で水増しされていないかを、元のサンプルを読んで確かめているか

採点目安: 18-20=情報の羅列を超えた深い洞察・因果関係/将来予測/相互関連性が充実 / 14-17=一定の洞察はあるが根拠がやや薄い・一部表面的 / 10-13=洞察が断片的で情報の羅列に近い / 0-9=洞察がほぼ無く転記・要約のみ

## 4. 構成・可読性【配点20点】
目的: 情報の整理・分類が適切で、読者が短時間で要点を把握できる構成になっているかを確認する。
- 情報がカテゴリ別・地域別に適切に整理・分類されているか
- 重要度順（または時系列順）に情報が並べられており、優先順位が明確か
- 見出し・表・箇条書きが効果的に活用されており、視認性が高いか
- プロンプトで指定された出力フォーマット（Markdown表・指定カラム等）に準拠しているか
- 要約が簡潔で、1項目あたりの文字数制限（70字以内等）が守られているか
- 表記の統一性が保たれているか（日付形式・カテゴリ名・用語の統一）
- 冗長な記述がなく、情報密度が適切か
- 読者が3分以内で全体像を把握できる構成になっているか

採点目安: 18-20=指定フォーマットに完全準拠+論理的整理+視認性高い / 14-17=おおむね準拠だが一部分類・並び順に改善余地 / 10-13=フォーマット逸脱が目立ち整理不十分 / 0-9=構成が混乱・フォーマット指定がほぼ無視

## 5. 実用性・アクション接続【配点20点】
目的: リサーチ成果物が読み手のビジネス判断に活用でき、次のアクションへ具体的に接続されているかを確認する。
- 収集された情報が読み手のビジネス判断・意思決定に直接活用できるか
- 次のアクション（投資判断・施策検討・コンテンツ制作・市場参入検討等）への接続が示されているか
- 競合情報・市場機会が具体的に特定されているか
- SEO分析の場合: キーワード戦略が実行可能であり、具体的な記事構成・導線設計まで落とし込まれているか
- SEO分析の場合: マネタイズ戦略（CTA配置・成約率向上策）が実装可能なレベルで記載されているか
- ニュース収集の場合: 各ニュースが自社ビジネスへの影響・対応策として解釈されているか
- 情報の優先順位づけがされており、「まず何をすべきか」が明確か
- 成果物をそのまま社内共有・報告に使えるクオリティか

採点目安: 18-20=具体的アクションに直結+競合/市場機会の特定明確+次ステップ提示 / 14-17=実用性はあるが一部抽象的 / 10-13=情報価値はあるが活用方法不明確 / 0-9=情報の羅列のみで実用性・アクション接続が皆無

## 6. 評価調整（プロンプト種別に応じる）
- ニュース収集系（news/*.md）: 「情報の正確性・信頼性」と「網羅性・カバレッジ」を重視観点とする
- SEO分析系（seo/*.md）: 「分析の深度・洞察」と「実用性・アクション接続」を重視観点とする
- 重視観点でも配点（各20点）は変えない。重視観点では、採点目安の 2 つの帯の境目で迷ったら低い方の帯を採り、評価コメントの先頭に重視観点として採点したことを書く。使用プロンプトが不明な場合は重視観点を置かない。
