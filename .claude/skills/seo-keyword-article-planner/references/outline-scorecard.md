# 記事構成の完成度 採点表（A〜F）

ステップ2の出力を返す前に、キーワードごとに A〜F を自己点検する。テンプレートは `article-outline-template.md`。自己点検は出力の品質確認であり、第三者レビューの代わりではない。

## 採点方法

各セクションを次の3段階で採点する。

| 記号 | 点 | 意味 |
|---|---|---|
| ○ | 2 | 下表の「○の条件」を全て満たす |
| △ | 1 | 項目は埋まっているが、条件の一部を満たさない（理由を書く） |
| × | 0 | 項目が欠けている、または「未確認」のまま放置している |

## セクション別の条件

| セクション | ○の条件 |
|---|---|
| A 基本情報 | 5項目（キーワード・文字数・ペルソナ・検索意図・競合優位性）が全て埋まり、ペルソナが年齢層や状況まで具体的で、競合優位性が競合調査の記録表の弱点に対応している |
| B タイトル・メタ | H1、サブタイトル3案、メタディスクリプション（約120文字）、スラッグ案が揃い、H1 と対象キーワードが対応している |
| C 見出し構成 | H1 から H2・H3 までの階層が示され、導入とまとめ・CTA を含み、検索意図の段階（情報収集・比較検討・購入検討）に沿った順序になっている |
| D セクション設計 | 全ての H2 に、執筆目的・含める内容・文字数目安・挿入要素・SEO要素が書かれ、文字数目安の合計が A の想定文字数に収まる |
| E マネタイズ | CTA の配置箇所とタイミングが具体的で、誘導文言・成約率向上策・離脱防止策が揃っている |
| F 技術的SEO | 構造化データの種類、内部リンクの方針、画像の alt 属性とファイル名の方針、表示速度対策が揃っている |

## 合否基準

- 合格: 合計 10 点以上（12 点満点）、かつ × が 0 件、かつ A・C・D がいずれも ○。
- 不合格: 上記のいずれかを満たさない。△ と × のセクションを直してから出力する。
- 直せない項目（検索ツールが使えず根拠を取れない等）は、×のままにせず「未確認」と理由を書き、末尾の「ユーザーに手動確認を依頼する項目」に載せる。この場合は合否の欄に「条件付き」と書く。
