# 企画書mdファイルからの16:9比率プレゼンテーションスライド生成プロンプト（プロフェッショナル版 v4.1）

原本（完全な HTML/CSS/JS テンプレート・コンテンツガイドライン・品質チェックリストの一次ソース）:
`workflows/content-creation/slides-pro.md`（リポジトリルートからの相対パス）

原本は 1599 行と長大なため、本 SKILL.md には要約のみ記載する（progressive disclosure）。
**スライド生成を実行する際は、上記原本ファイルを Read し、そこに記載された完全な HTML/CSS/JS
テンプレート・絶対ルール・ガイドラインを一切省略・改変せずそのまま適用すること。**

対応するレビュープロンプト: `.claude/skills/review-slides/SKILL.md`

## 何をするか

ベテランITコンサルタントの視点から最適化された、企画書の md ファイルから 16:9 比率のプレゼンテーション
スライドを HTML と CSS で自動生成するシステム。実際のビジネスプレゼンテーションで求められる要素を網羅し、
視認性と操作性を最大化する。

## 絶対ルール（v4.1、詳細は原本参照）

1. CSS変数（`var(--xxx)`）は使用禁止 → 直接カラーコードを記述
2. すべてのテキスト要素に明示的な `color` を指定
3. 背景色と文字色のコントラスト比 4.5:1 以上を確保
4. 1スライドの情報量を制限（箇条書きトップレベル5項目以内・ネスト含み10項目以内・テーブル6行以内・
   カード4枚以内・段落テキスト3段落計150文字以内）→ 超えたらスライドを分割（フォント縮小で詰め込まない）
5. スクロールバーを必ず有効化（`.slide-content` に `overflow-y: auto`、長い場合の保険）

## 生成前の事前処理（必須）

1. 現在の日付を web_search 等で取得し、タイトルスライド・最終スライドの作成日に使用する
2. 日本語表記（例: 2026年8月27日）または英語表記でフォーマット

## 生成手順

1. 原本ファイル (`slides-pro.md`) を Read し、完全な HTML テンプレート（`<!DOCTYPE html>` から
   `</html>` まで、`PresentationManager` クラス・キーボード/タッチナビゲーション・PDF出力・
   印刷用 `@media print` スタイルを含む）をベースに使用する
2. 引数で渡された企画書 md ファイルの内容を Read し、内容をスライドへ構造化する
3. フォントサイズガイドライン（h1: 36px/タイトルh1: 48px、h2: 26px、h3: 20px、本文: 20px、補足: 16px）
   を厳守する
4. 情報量ガイドラインに従いスライドを分割する（多すぎる情報を1スライドに詰め込まない）
5. 最終スライドは「Thank You」で終わらせず、`.summary-slide` 形式で重要ポイント3〜5個 + 各ポイントの
   参照ページ番号（`.summary-page` → p.X）+ Next Action（あれば）を含める
6. 生成した単一 HTML ファイルを Write する

## 生成後の品質チェックリスト（原本より、必ず確認）

- 視認性: タイトルスライドの文字が白色、通常スライドの文字が濃い色、カード内テキストが読める、
  CTAボックス内テキストが白色、遠くからでも読めるフォントサイズ
- レイアウト: 箇条書きが5項目以内、テーブルが6行以内、コンテンツがはみ出していない、スクロールバーが機能する
- 最終スライド: 「Thank You」だけで終わっていない、重要ポイント3〜5個、参照ページ番号あり、Next Action記載
- 機能: ← → キーでスライド移動、PDF出力ボタンが機能、プログレスバーが更新、スライド番号が正しい

## 禁止事項（原本より）

1. CSS変数 `var(--xxx)` の使用
2. `color: white` の曖昧な記述（`#ffffff` を使用）
3. 背景色と同系色の文字色
4. 1スライドに6項目以上の箇条書き
5. スクロールバーの無効化
6. 最終スライドを「ご清聴ありがとうございました」だけで終わらせる

## 出力後

生成した HTML ファイルの完全パスをユーザーに報告する。レビューが必要な場合は `.claude/skills/review-slides/SKILL.md` を使用する（別エージェントでの客観的レビュー、自己レビューしない）。
