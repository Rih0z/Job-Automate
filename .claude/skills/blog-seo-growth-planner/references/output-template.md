# 最終出力テンプレート

SKILL.md の「最終出力の構成」8 節それぞれの必須フィールド。該当しない節は「対象外（理由）」と書く。

## 目次

- 1. 前提
- 2. 現状分析
- 3. 競合・市場調査
- 4. キーワード一覧
- 5. コンテンツ戦略とSEO方針
- 6. 記事素案
- 7. ロードマップ
- 8. KPI と測定方法

## 1. 前提

| 項目 | 内容 |
|---|---|
| ジャンル / 目的 / 読者 | ヒアリング結果 |
| 運営期間 / 月間PV | 不明なら「不明」 |
| 調査日 | YYYY-MM-DD |
| 未調査項目 | 項目名と理由（なければ「なし」） |

## 2. 現状分析（既存ブログのみ）

箇条書き: 記事数・更新頻度 / 主要カテゴリ / 人気記事の傾向 / タイトル・メタ・内部リンク・画像の状況。各項目に根拠（URL）か「推測」を付ける。

## 3. 競合・市場調査

| 競合ブログ | URL | 強み | 弱み | 更新頻度 | 出典・取得日 |
|---|---|---|---|---|---|

5 件以上。続けて「差別化ポイント」「直近のトレンド・季節要因」を各 3 行以内で書く。

## 4. キーワード一覧

| 区分 | キーワード | 検索意図 | 検索ボリューム（数値または 高/中/低（推定）） |
|---|---|---|---|

区分はメイン（3〜5）/ ロングテール（10〜15）/ 関連・急上昇。

## 5. コンテンツ戦略とSEO方針

- ピラー 3〜5 件（テーマ名と打ち出す専門性を 1 行ずつ）
- 更新頻度（週○本）とその算出根拠
- 差別化の提案
- オンページ施策 / コンテンツ施策（E-E-A-T 向上を含む）。各項目に「直近のアルゴリズム更新との関係」を 1 行
