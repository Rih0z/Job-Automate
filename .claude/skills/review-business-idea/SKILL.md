# /review-business-idea — ビジネスアイデア 品質レビュー（エージェント分離実行）

> **このスキルは別エージェントを起動してレビューを行う。現在のセッションでは直接レビューしない。**
> アイデア作成時の思考過程・設計判断・会話履歴をレビューエージェントに渡さないことで客観性を確保する。

対象: `business-idea` skill をもとに発展・整理されたビジネスアイデア文書
目的: 「独自性・競合克服戦略」「市場性・成長性」「実現可能性」「ペルソナ明確性」「エンゲージメント・リテンション設計」「展開計画の具体性」の6軸で100点満点評価する。

---

## 実行手順

### ステップ1: 情報収集（この実装セッションで行う）

以下の事実情報のみを収集する。作成の意図・設計判断の説明は**含めない**。

```
収集対象:
1. レビュー対象のビジネスアイデア文書の全文
2. 以下の「レビュー前の必須確認事項」が文書内または作成者からの回答で判明しているか
   - このビジネスアイデアで解決したい課題は何か（1〜2文で言語化できるか）
   - 誰のために・誰が使うビジネスか（ターゲット顧客・ペルソナの明示有無）
   - このアイデアをどの段階まで発展させたいか（検討段階・投資検討・実行フェーズ）
   - `business-idea` skill のどのステップまで使ったか
```

上記が不明瞭な場合は、レビュー開始前に作成者へ確認すること。

### ステップ2: レビューエージェント起動

**Agent ツール**を使い、以下の設定で別エージェントを起動する:

```
Agent ツールの設定:
- subagent_type: "general-purpose"
- description: "Review business idea objectively"
- prompt: 以下のテンプレートに収集した情報を埋め込む
```

**プロンプトテンプレート（レビューエージェントに渡す内容）:**

```
あなたは作成者とは別の客観的な事業開発の専門家です。
以下のビジネスアイデア文書を、6項目・合計100点で評価してください。

## レビュー観点（6項目・合計100点）

### 1. 独自性・競合克服戦略 【配点：20点】

> 目的：このビジネスアイデアが既存の競合・代替手段と明確に差別化されており、独自の価値提案（UVP）を持ち、競合の強みを克服する具体的な戦略があるかを確認する。

- [ ] 独自の価値提案（UVP）が1〜2文で明確に言語化されているか
- [ ] 既存の競合サービス・代替手段との比較が含まれているか
- [ ] 競合が提供していない「このアイデアだけができること」が示されているか
- [ ] 差別化要因に持続性があるか（技術・特許・ネットワーク効果・ブランド等による参入障壁）
- [ ] 「なぜ今このビジネスなのか」という時代背景・市場タイミングの説明があるか
- [ ] 競合の強みを無力化するカウンター戦略が示されているか
- [ ] 競合の弱みを突く具体的なアプローチが特定されているか
- [ ] 競争優位の持続性（モート）が分析されているか（ネットワーク効果・スイッチングコスト・データ蓄積・ブランド・特許等）
- [ ] 競合の次の動き（反応）を予測し、それに対する準備があるか

採点目安:
| 点数 | 基準 |
|------|------|
| 18〜20 | UVPが明確で競合比較が揃い、差別化の持続性と市場タイミングが示されている。競合克服戦略・モート分析・競合反応予測まで含まれている |
| 14〜17 | おおむね独自性はあるが、競合比較または差別化の持続性の説明が不十分。競合克服戦略の一部が欠けている |
| 10〜13 | 独自性の説明が表面的で、既存サービスとの違いが不明確。競合克服の具体策がない |
| 0〜9  | 既存ビジネスとほぼ同一で、差別化要因がほぼ示されていない |

### 2. 市場性・成長性 【配点：15点】

> 目的：TAM/SAM/SOM分析に基づき、このビジネスアイデアが十分な市場規模と成長ポテンシャルを持っているかを確認する。

- [ ] TAM（Total Addressable Market：全体市場規模）が数値で示されている
- [ ] SAM（Serviceable Addressable Market：アプローチ可能市場）が定義されている
- [ ] SOM（Serviceable Obtainable Market：獲得可能市場）と初期目標が示されている
- [ ] 市場の成長トレンド（現在の成長率・将来予測）が含まれているか
- [ ] 市場規模の根拠（データソース・調査結果）が明記されているか
- [ ] マネタイズ方法（収益モデル・価格設定）が具体的に示されているか

採点目安:
| 点数 | 基準 |
|------|------|
| 14〜15 | TAM/SAM/SOM分析が揃い、成長トレンドと収益モデルが具体的に示されている |
| 11〜13 | 市場分析は含まれるが、TAM/SAM/SOMの一部または収益モデルが不十分 |
| 7〜10 | 市場分析が表面的で、規模感や成長性の根拠が乏しい |
| 0〜6  | 市場分析がほぼなく、ビジネスとして成立するかの評価が困難 |

### 3. 実現可能性 【配点：15点】

> 目的：このビジネスアイデアを実際に立ち上げるために必要なリソース・リスクが現実的に評価されているかを確認する。

リソース評価チェック:
- [ ] 立ち上げに必要な初期投資・コストが概算で示されているか
- [ ] 必要な人材・スキル・技術が特定されているか
- [ ] MVP（最小限の製品）または検証可能な最初のステップが示されているか

リスク評価チェック:
- [ ] 主要リスク（市場リスク・技術リスク・規制リスク・競合リスク等）が列挙されているか
- [ ] 各リスクに対する緩和策・対応策が示されているか
- [ ] 「うまくいかない場合」のピボット（軌道修正）の可能性に言及があるか

採点目安:
| 点数 | 基準 |
|------|------|
| 14〜15 | リソース・MVP・リスクと対策がすべて含まれ、現実的な評価がされている |
| 11〜13 | おおむね評価されているが、一部のリスクまたはリソース見積もりが不十分 |
| 7〜10 | 実現可能性の評価が表面的で、現実的な課題への言及が少ない |
| 0〜6  | 実現可能性の検討がほぼなく、アイデアの実行可能性が不明 |

### 4. ペルソナ明確性 【配点：15点】

> 目的：ターゲット顧客のペルソナが具体的に定義されており、ビジネス全体がそのペルソナの課題解決に集中しているかを確認する。

- [ ] 具体的なペルソナ（年齢・職業・ライフスタイル・悩みなど）が設定されているか
- [ ] ペルソナが抱える課題・ペインポイントが具体的に描写されているか
- [ ] このビジネスがペルソナの課題をどのように解決するかが明確に示されているか
- [ ] ペルソナが「なぜこのサービスを選ぶか」の動機が説明されているか
- [ ] ペルソナに対する獲得チャネル（どこで・どうやって出会うか）が示されているか
- [ ] ペルソナが複数いる場合、プライマリ（主要）ペルソナが特定されているか

採点目安:
| 点数 | 基準 |
|------|------|
| 14〜15 | ペルソナが具体的で、課題・解決策・獲得チャネルまで一貫して定義されている |
| 11〜13 | おおむね明確だが、ペルソナの一部（動機・獲得方法等）が不十分 |
| 7〜10 | ペルソナが抽象的で、「誰のためか」が漠然としている |
| 0〜6  | ターゲット顧客の定義がほぼなく、誰向けのビジネスかが不明 |

### 5. エンゲージメント・リテンション設計 【配点：20点】

> 目的：ユーザーが継続的にサービスを利用し、離脱しにくくなる仕組みが設計されているかを確認する。ドーパミン報酬・習慣形成・ネットワーク効果など、行動科学に基づいたエンゲージメント戦略の有無と質を評価する。

習慣ループ・行動設計チェック:
- [ ] トリガー設計（外的：通知・メール / 内的：感情・習慣）が定義されているか
- [ ] 報酬設計（変動報酬：達成感・社会的承認・自己実現・金銭的リターン等）が具体的か
- [ ] 投資設計（ユーザーがサービスに蓄積する価値：データ・カスタマイズ・人間関係・実績）が含まれているか
- [ ] 行動経済学・心理学の原理（損失回避・サンクコスト効果・社会的証明・進捗効果等）が活用されているか

リテンション・離脱防止チェック:
- [ ] ネットワーク効果（ユーザー増加に伴う価値向上）の仕組みがあるか
- [ ] スイッチングコスト（データロックイン・コミュニティ・エコシステム統合等）が設計されているか
- [ ] ゲーミフィケーション要素（ストリーク・バッジ・レベル・ランキング等）が検討されているか
- [ ] リテンション指標（DAU/MAU・コホート別継続率・チャーン率等）の目標が設定されているか
- [ ] チャーン予兆検知と介入戦略が計画されているか
- [ ] ユーザーライフサイクル別のエンゲージメント施策が設計されているか

採点目安:
| 点数 | 基準 |
|------|------|
| 18〜20 | 習慣ループ・報酬設計・ネットワーク効果・リテンション指標がすべて設計され、行動科学に基づいた根拠がある |
| 14〜17 | おおむね設計されているが、一部（報酬設計やリテンション指標等）が不十分 |
| 10〜13 | エンゲージメント設計が表面的で、具体的な行動科学の根拠や指標が欠けている |
| 0〜9  | エンゲージメント・リテンション設計がほぼなく、ユーザーが継続利用する仕組みが不明 |

### 6. 展開計画の具体性 【配点：15点】

> 目的：ビジネスアイデアを実際に動かすための段階的な展開計画が具体的に示されているかを確認する。

- [ ] フェーズ分け（例：検証フェーズ→MVP→スケール）が定義されているか
- [ ] 最初の100日間（または3ヶ月）で何をするかが具体的に示されているか
- [ ] 成功指標（KPI）が定量的に設定されているか（顧客数・売上・継続率等）
- [ ] 最初の顧客をどうやって獲得するかの具体的な方法が記載されているか
- [ ] 事業をスケールさせるための仕組み（口コミ・SEO・パートナーシップ等）が示されているか
- [ ] 長期的なビジョン（3〜5年後のあるべき姿）が示されているか

採点目安:
| 点数 | 基準 |
|------|------|
| 14〜15 | フェーズ・KPI・獲得方法・スケール戦略が揃い、長期ビジョンまで示されている |
| 11〜13 | おおむね具体的だが、一部の計画（KPIや獲得方法等）が不十分 |
| 7〜10 | 展開計画が抽象的で、「まず何をするか」が不明確 |
| 0〜6  | 展開計画がほぼなく、アイデアのままで止まっている |
