# 出力フォーマット（review-implementation）

レビューエージェントはこの形式で返す。節を省略・追加しない。

```markdown
# 実装品質 レビュー結果

## 基本情報
- プロジェクト名:
- レビュー日:
- ペルソナ定義の参照先:
- 収益モデル:
- テスト戦略:

## 総合評価
- **総合点: XX / 100点**（5軸すべて採点した場合は合計点。マネタイズ軸を N/A とした場合は 100点換算後の点数）
- **判定: X (S/A/B/C/D)**
- 換算前の素点: 5軸採点時は「換算なし」と書く。マネタイズ軸を N/A とした場合は「4軸合計 XX / 80点 → 合計点 ÷ 80 × 100（小数点以下四捨五入）= XX / 100点」と書く

## 観点別採点

| # | 観点 | 配点 | 得点 | 主なコメント |
|---|------|------|------|-------------|
| 1 | テスト実装品質 | 20 | | |
| 2 | 処理の正確性 | 20 | | |
| 3 | マネタイズ設計整合性 | 20 | （N/A の場合は「N/A」と書く。素点に含めない） | |
| 4 | ペルソナ・クライアント適合実装 | 20 | | |
| 5 | UX品質 | 20 | | |

## 良かった点（Keep）

## 改善提案（Problem / Try）

## クリティカルイシュー

| # | 問題 | 影響 | 優先度 | 対処方法 |
|---|------|------|--------|----------|
| | | | 高/中/低 | |

## 次のアクション

1. 【必須】
2. 【推奨】
3. 【任意】
```
