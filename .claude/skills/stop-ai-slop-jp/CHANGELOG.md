# Changelog

## [0.2.2-local] - 2026-10-08 (ローカル翻案・upstream 未反映)

### 追加

- `blocker_checks` に `single_meaning`(意味の一意性)を追加した。主語・述語・目的語が読み取れない文、「対応する」のように状態と方針の両方に読める語、「のみ」「〜向け」の限定の脱落、変化に見える書き方のために、文書の対象読者が書き手の意図と違う事実に取る文を、最優先で是正する対象にした。レビュアは割れる文ごとに読み方 A・B と書き手の意図を示す。読み方を 2 つ挙げられない文、日本語で自然な主語の省略で別の事実に取られないものは対象にしない。
- `SKILL.md` のクイックチェックと修正の優先順位の 0 番、`select-slop-viewpoints` の blocker 一覧と全ての種類の blocker にも追加した。
- スコア・`pass_rule`・5 軸は変えていない。
- 理由: 製品の対応状況を書いた要約で、1 つの文が「今使える」とも「対応する方針」とも読め、別の事実に取られる誤りが繰り返し見つかった。既存の `agency` 軸と R01 は「誰が何をしたか」を見るが、読み方が 2 通りに割れる文を止める基準が無かった。

## [0.2.1-local] - 2026-10-07 (ローカル翻案・upstream 未反映)

### 追加

- `blocker_checks` に `instruction_echo`(指示文のメモ書き化)を追加した。依頼者の指示にある言い回し(括弧書きのラベル、「〜のタブにある」のような画面の案内)が、読み手向けの語に直されないまま見出し・固定文・本文に出る誤りを、スコアに関わらず最優先で是正する。生成 script の固定の見出し・固定文も対象に含める。
