# ソース検証スキャン(非公開情報・伝聞・捏造導線チェック)

## 目的

外部公開する調査・レポート・記事に、公開情報で裏付けられない記述が残っていないかを系統的に検査する。**「事実は正しいが、位置付け・フレーミングが未確認」というパターン**を含めて検出する。

## ゼロ・トレランス原則

公開情報にない情報は、フレーミング・位置付け・推測・要約も含めて一切の混入を許さない。「未確認」「要追加確認」等の注記付きでも保持不可。出典で literal 確認できないものは削除、または裏付けの取れる公開出典への置換のみ許容する。

## 禁止対象カテゴリ

| ID | 種別 | 検査方法 |
|---|---|---|
| A | 非公開契約・機密情報下で得た情報 | "NDA" "confidential" "internal" 等の grep + 出典追跡 |
| B | クローズドな会議・限定公開の場での発言 | "非公開" "関係者限定" "招待制" 等の grep |
| C | 業界の噂・伝聞・匿名SNS投稿 | 「らしい」「とされる」「聞いている」等の grep + 具体URLの有無。**例外**: 発信主体が検証済み(本人/組織公式アカウント)かつpermalink付き・literal確認済みの発言は条件付き一次情報として扱ってよい(噂と取り違えない) |
| D | 一次到達不可の二次解説のみの情報 | 原典URLが示されない解説記事・まとめ記事からの引用 |
| E | 自組織だけが知る内部情報 | 案件名・金額・内部資料等の grep |
| F | **literal未確認の数値・日付・引用**、および**捏造された参照先・配布先** | 「要追加確認」等の grep、および記事が案内する参照先(URL・フォルダパス・「メニューのXからYを参照」等)が実在し、記事内の resolvable な実URLと一致するかを1件ずつ確認(grep だけでは検出できない。ナビゲーション文言が指す先と実URLの指す先が一致するかまで確認する) |
| G | フレーミング・位置付け・分類自体が公開情報で確認不可 | 「新機能」「業界の主流」「今後の方向性」等の断定を、公式発表URLと1行ずつ突合。事実は正しくても位置付けの断定に出典がなければ違反 |

## 許容される出典

一次情報源(公式ドキュメント・公式ブログ・公開カンファレンス発表・vendor公式docs・原典URL明記の報道・公開書籍/論文)、および検証済み・permalink付き・literal確認済みの公式SNS発言(条件は上記C参照)。二次情報源のみを一次として扱わない。

## launder禁止の原則(取得手段が変わっても不変)

非公開ソースが禁止されている理由は「取得手段」ではなく「ソースが非公開であること」自体にある。WebFetchで直接取得できないからと別の技術的手段(スクレイピング・HTML dump等)で取得しても、非公開ソースを「引用可能な公開ソース」に変えることはできない。公開一次ソースへのアクセスが技術的に失敗した場合のみ、別の取得手段を試みてよい(非公開ソースへの適用は不可)。

## スキャン手順(別エージェント実行)

呼び出し元セッションの意図・執筆過程は渡さず、対象ファイルのパスと本skillの禁止カテゴリ(A-G)のみを渡して別エージェントに検査させる(自己レビュー禁止)。

出力形式(各hitについて):
```
- 行番号 + literal quote
- 該当カテゴリ: A-G
- 判定: 公開OK / 非公開NG
- 推奨処置: 出典URL追加 / 行ごと削除 / 表現の中立化
```

最後に converged BLOCKER リストとサマリを出す。BLOCKERが0件になるまで公開しない。

## 対応アクション

- **行ごと削除**: 裏付けが取れないものはそのまま消す(訂正注記を残して保持しない)
- **公開出典への置換**: 同内容が公開一次情報で確認できる場合はURLに置換
- **表現の中立化**: 自組織の内部情報は削除し、業界一般化した表現に置き換える
