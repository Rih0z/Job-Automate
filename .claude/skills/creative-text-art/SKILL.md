# 超高級ゴンベ顔文字作成プロンプト

装飾的で立体的な可愛いゴンベ顔文字（`ʕ•ﻌ•ʔฅ` や `٩꒰ ˘ ³˘꒱۶~♡` のようにフレーム・装飾・ポーズを含む）を作る。

本 skill は `references/parts-catalog.md` を含めて単体で完結しており、他の資料は不要。

## 入力と出力の約束

- 入力: 気分・状況（食べる/寝る/甘える/遊ぶ）、装飾レベル（1〜5）、任意でキャラクター名。指定が無ければ気分はユーザーの文脈から推定し、レベルは 3 を既定とする。
- 出力: 顔文字 3 案（レベルを 1 つずつ変えるか、同レベルで気分違い）。各案を 1 行のコードブロックで示し、直後に使ったフレーム・目・口・装飾を 1 行で添える。パーツ図鑑全体の再掲はしない。
- 完了判定（出す前に各案を数えて確認する。1 つでも満たさなければ作り直す）: (a) フレームが左右で閉じている (b) 目・口・装飾の 3 要素を含む (c) 装飾記号（♡ ♪ ✧ ~ ≈ ◦ 手の記号など）の個数が指定レベルの下限以上: レベル1=1個、2=2個、3=2個、4=3個（左右に各1個以上）、5=5個（左右に各2個以上） (d) 既存テンプレート例の丸写しでなく、目・口・装飾のいずれかを変えている (e) 気分に対応するフレーム・目・口の組み合わせを使っている。
- 失敗時の対処: レベルが 1〜5 の範囲外ならユーザーに範囲を伝えて 3 を使う。気分とレベルの指定が矛盾する場合（例: 眠いのにレベル5）は、指定レベルを優先して装飾を増やし、その旨を 1 行添える。
- 表示環境の注意: `ﻌ`（アラビア文字）、`ೀ`、`ᘛ` 等はフォントによって豆腐（□）や幅ずれになる。送信先が不明な場合は、記号が少なめの代替案を 1 案添える。ユーザーが文字化けを報告したら、該当パーツを `•`・`◉`・`ω`・`♡` などの一般的な文字に置き換えて再提示する。
- 使用例 1（成功）: ユーザー「ご飯食べてる顔文字、レベル4で」→ 食べる系フレーム `ೀ ೃ` + 丸目 + `ω` + 装飾で 3 案 → 例 `◦ೀ ◉ω◉ ೃ◦🍯♡`（解説 1 行付き）。
- 使用例 2（別の気分・低レベル）: ユーザー「眠い感じ、シンプルに」→ 気分=寝る、レベル指定なしなので既定の 3 ではなく「シンプル」を読み取ってレベル1〜2 で 3 案 → 装飾 1〜2 個の案を出し、各案にフレーム・目・口・装飾を 1 行で添える。
- 使用例 3（例外）: ユーザー「顔文字をレベル7で」→ 範囲外なので「レベルは 1〜5」と伝え、レベル3 で 3 案を出す。ユーザー「顔文字が □ になる」→ 該当パーツ（`ﻌ` など）を `•` `◉` `ω` に置き換えて再提示する。ユーザー「ロゴを作って」→ 対象外（画像生成）なので本 skill は使わず、その旨を伝える。

## 作り方

1. 気分（食べる/寝る/甘える/遊ぶ）とレベル（1〜5）を決める。
2. `references/parts-catalog.md` を Read し、気分に対応するフレーム・目・口・装飾をその図鑑から選ぶ（気分別の組み合わせ例は同ファイルの「感情・状況別作成法」）。
3. 同ファイルの「レベル別テンプレート集」の該当レベルを手本に、上の完了判定 (a)〜(e) を満たす顔文字を 3 案作る。
4. 出力形式（上の「入力と出力の約束」）に従って返す。

図鑑の内容: 構造分析、フレーム、目・鼻口パーツ、手・ポーズ記号、装飾エフェクト、レベル1〜5 のテンプレート、気分別の作成法、非対称・多層装飾などの創作テクニック。
