# プロンプトシステム

SKILL.md から分離した詳細。目的別プロンプトファイルの配置・分類・使用ルール。

### プロンプトファイルの配置場所
運用対象サーバー/リポジトリの `server/prompt/` ディレクトリ相当の場所に、新規記事作成や特定作業
のための専用プロンプトを配置・管理する。

### プロンプトファイル一覧の例
1. ブログ専用記事テーマ決定プロンプト（新規記事のテーマ決定）
2. 業界/ジャンル別情報収集プロンプト（国内/海外の業界情報収集）
3. HTML編集マスターガイド（記事の編集・更新作業）
4. アフィリエイト商品挿入プロンプト（アフィリエイト商品の適切な挿入）
5. HTMLコンテンツ翻訳ガイド（翻訳作業）
6. モバイル最適化レビュー構成要素ビジュアライズ（モバイル端末向け記事構成最適化）
7. ファクトチェックガイド（記事の事実確認・品質管理）

### プロンプト分類と使用原則

#### 新規記事作成プロンプト（HTMLファイル作成OK）
- ブログ記事テーマ決定プロンプト、業界情報収集プロンプト、SEO検索ワードからの新記事作成、
  新規紹介記事等 — 新しい対象の紹介記事

#### 既存記事更新プロンプト（HTMLファイル作成禁止）
以下を組み合わせて包括的に更新する:
1. HTML編集マスターガイド — キャラクターシステムの導入、ファクトチェック済みバッジ、SEO最適化
   要素、免責事項の追加
2. ファクトチェックガイド — 確認済み事実セクションの追加、主観的評価の明示、情報源の明記
3. アフィリエイト商品挿入プロンプト — 購入リンク、関連グッズの紹介、ペアリング商品
4. モバイル最適化レビュー構成要素 — レスポンシブデザイン、タッチフレンドリーUI、表示速度最適化

**重要**: これらのプロンプトは単独ではなく、統合的に適用して包括的な改善を実施する。

#### 更新系プロンプトの厳格なルール
- 既存のHTMLファイルを直接更新・編集する
- 元のURL・ファイル名・post_idを完全に保持
- 既存記事の改善・強化のみ実施
- 記事の基本構造は維持し、内容の精度向上や機能追加のみ
