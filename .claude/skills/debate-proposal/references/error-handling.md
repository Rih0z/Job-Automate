# エラー処理 (Step 2〜3 で論者の結果が不完全なとき)

SKILL.md の Step 3 から参照される。

| 状況 | 次の手順 |
|---|---|
| 論者が失敗・タイムアウトした | 同じ prompt で 1 回だけ再起動する。再度失敗したら、その論者を欠いたまま進めず、欠けた役割を出力に明記して依頼者に報告する (2 論者だけで裁定しない) |
| 結果に `<file>:<line>` 引用が無い・確信度が無い | `SendMessage` で該当節の引用と確信度の補完を依頼する (1 回)。補完されない主張は裁定の根拠から外し、「引用なしのため除外」と記す |
| 「なし」と書かれ調査した path が無い | proof by absence として扱い、調査 path の提示を再依頼する。出なければ SUSPECTED 扱いにする |
| 数値が論者間で食い違い、本セッションでも一次資料から確定できない | 確定を保留し、両方の値と出所を並記して対立点に入れる。依頼者の判断に上げる |
| 食い違いが毎回繰り返される (同じ証跡ファイルが上書きされる等) | 原因を発見事項に記録し、証跡を固定 (コピー) してから第 2 ラウンドをやり直す |
| 論者の出力が指定の節構成から崩れている | 節の見出しだけ再提出を依頼する。内容が読み取れるなら、本セッションが節に振り分けて統合し、振り分けたことを明記する |
| 5 観点評価に尺度外の値や根拠なしの行がある | 尺度 (良 / 要注意 / 不可) と書式での再提出を 1 回依頼する。直らなければ根拠なしの行を「要注意・確信度 SUSPECTED」として扱い、その旨を記す |
